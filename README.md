# Tumbuh App

> **Tagline:** Grow with intention.

Tumbuh is a minimalist growth companion designed for mindful living. Inspired by Islamic values and sustainable habits, it helps users grow holistically—financially, spiritually, and mentally—through guided reflections, habits, and personalized insights. The experience celebrates gratitude, balance, and purposeful progress.

## Vision & Concept
- Encourage continuous, mindful self-improvement that blends personal development, financial mindfulness, and faith-driven guidance.
- Extend naturally into the broader Tumbuh Living ecosystem of sustainability and lifestyle initiatives.

## Core Features (MVP)
- Guided reflections, gratitude journaling, and habit tracking that cultivate spiritual and mental growth.
- Financial mindfulness tools that surface insights, bill summaries, and savings progress.
- Personalized recommendations and AI-assisted prompts rooted in Islamic principles.

## Visual Identity
- **Palette:** Dark Emerald `#033B2C` and Gold `#D4AF37`.
- **Typography:** Clean, rounded sans-serif typefaces (e.g., Poppins, Noto Sans).
- **UI Style:** Minimalist Japandi calm with rounded cards, soft shadows, ample whitespace, and subtle glow.

## Technical Direction
- Flutter-based (React prototype supported for Codex integrations).
- Firebase recommended for backend hosting and authentication simplicity.
- Domain connection in progress (`tumbuh.my` preferred, `tumbuh.app` under consideration).
- Public GitHub repository with CI/CD (Codex, Vercel, or Firebase Hosting) for automated deployment.

## Deployment Roadmap
1. Finalize backend hosting and environment configuration.
2. Connect the chosen custom domain.
3. Initialize the GitHub repository with this README and initial commit.
4. Push the MVP prototype and enable continuous deployment.

## Long-term Growth
- **Personal Growth Companion:** AI-guided daily reflections, Qur'an-inspired prompts, gratitude archives.
- **Financial Mindfulness Module:** Goal projections, savings visualizations, and bill management integrations.
- **Family & Wellness Extension:** Habit trackers for nutrition, sleep, and support for partner-led lactation wellness services.
- **Community Growth Hub:** Shared reflections, environmental challenges, and spiritual learning circles.

## Monetization Ideas
- Freemium access with premium coaching templates, advanced analytics, and exclusive themes.
- Subscription tiers (monthly/yearly) for deeper insights and personalized support.
- Affiliate partnerships with sustainable living brands and curated eco-products marketplace.

## Core Philosophy
Tumbuh is not about doing more—it is about growing better. By fusing faith, mindfulness, and progress, the app nurtures sustainable growth grounded in gratitude, serenity, and purpose.
